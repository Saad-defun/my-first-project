# Working rules

## Discuss first, act only on explicit request (strict)

1. **Discuss only**: answer questions, explore options, propose plans. Do not edit files, commit, push, create PRs, or take any other action.
2. **Finalize**: agree on the approach with the user.
3. **Act**: do the work only when the user asks for it in a separate message (e.g. "do it", "implement it").
